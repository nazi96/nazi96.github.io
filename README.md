## Updating the site

Changes pushed to `master` are published automatically by GitHub Pages within a few minutes.

| To change… | Edit |
| --- | --- |
| Intro and homepage | `_pages/about.md` |
| Profile photo | `images/profile-photo.jpg` |
| CV | Replace `files/Nazanin_resume.pdf` (keep the same name) |
| Name, bio, sidebar links | `_config.yml` |
| Top menu | `_data/navigation.yml` |
| Styles (fonts, links, cards, layout) | `assets/css/homepage-custom.css` |

**Adding a publication:** copy an existing file in `_publications/`, update its fields (`title`, `date`, `venue`, `authors`, `arxivurl`, `projecturl`, `bibtex`), and add a thumbnail to `images/publications/`. It appears on both the homepage and the Publications page, newest first.
